# finalproject

Final project for BST260 by Jeremiah Gorremuchu.

This project examines homicide mortality before and after permit-less
concealed-carry adoption in states with high mortality rate. Using CDC homicide mortality data and RAND
firearm legislation records, trends across states will be investigated. 

[Read the project proposal](https://jeremiah-pg.github.io/finalproject/articles/proposal.html)
